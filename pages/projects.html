__ XR Meditation _____________________
Affiliation: University of Oulu
Unreal Engine 5 Blueprint scripting Meta Quest 3

The XR Meditation VR prototype was developed in Unreal Engine 5 and optimized for deployment on the Meta Quest devices, with the long-term aim of providing a consumer-level meditation experience. It was developed as both a meditation tool and a research instrument to examine how persuasive elements influence Cognitive Absorption and user perceptions of usability and usefulness.

  • Designed immersive forest environments, meditation spots, and interactive elements.
  • Integrated haptic feedback for Meta Quest controllers to enhance user immersion.
  • Implemented dynamic dialogue systems and collision detection for environmental interactions.
  • Built an interactive meditation system that adapts the environment based on user actions.
  • Created widget-based menus and integrated voice interaction functionality.
  • Maintained version control using Diversion to collaborate with other developers.
